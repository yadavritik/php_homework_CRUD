# PHP_Homework2_CRUD

## This project demonstrate CRUD operations using PHP and MySQL. Users can insert, update, delete and display data in a table.

## Technology Used
- **PHP**
- **MySQL**
- **HTML**
- **XAMPP**

## Features
- **Insert Employee Data**
- **Update Employee Salary**
- **Delete Employee Record**
- **Display Employee Records**

## Database

**Database Name:** employee_db

**Table Name:** employee, employees

**Columns**
- **id**
- **name**
- **position**
- **salary**
